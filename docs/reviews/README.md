# Reviews (historical)

These are findings files written by the retired `/check review` mode, which
spawned a contrasting-model reviewer and saved its verdict here. That mode was
removed on 2026-09-20: the built-in `/code-review` skill does the same job with
effort levels, inline PR comments, `--fix`, and a deep multi-agent `ultra` mode,
and `/predeploy-audit` already chains it at high effort.

Nothing writes to this directory any more. The files below are kept as the
record of the reviews that did run; code review findings now live on the PR.
